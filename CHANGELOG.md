# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-06

### Added
- Initial release
- Self-measuring adaptive bottom sheet component
- Gesture-driven drag-to-close functionality
- Keyboard avoidance support
- Customizable header component
- Portal-based rendering system
- Spring animations with Reanimated 3
- Safe area support
- TypeScript definitions
- Support for fixed and max height configurations
- Optional backdrop dismiss control
- onDismiss callback support

### Features
- `AdaptiveBottomSheet` - Main bottom sheet component
- `useBottomSheet` - Hook for controlling bottom sheet state
- `AdaptiveBottomSheetProvider` - Required root provider component
- Smooth 60fps animations
- Automatic content height measurement
- Customizable theme support
- Close button with custom icon
